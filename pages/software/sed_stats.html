Sed/Stats is a multivariate-first web app for analyzing sedimentological data. It is coded entirely in Python, made available as a web app through Pyodide/Web Assembly and a homebrewed frontend framework currently called Antioch. Currently, I am working on integrating the app with Google Drive so that users can load and save their work from anywhere. Along with the current sedimentological methods, I also plan on integrating analyses for hydrological and isotopic data.
